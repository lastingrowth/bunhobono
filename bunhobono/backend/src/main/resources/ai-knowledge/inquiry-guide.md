# FAQ 및 1:1 문의 안내

## FAQ 확인

1:1 문의를 등록하기 전에 FAQ에서 관련 질문을 확인한다. FAQ에는 주차, 방문차량, 결제 및 기타 서비스 이용 안내가 등록될 수 있다.

FAQ만으로 해결되지 않거나 본인 데이터 확인, 관리자 판단 또는 예외 처리가 필요한 문제는 1:1 문의를 이용한다.

## 문의 등록

입주민은 로그인 후 `1:1 문의`에서 문의하기 화면으로 이동해 문의를 등록한다.

선택 가능한 문의 분류는 다음과 같다.

- 주차(`PARKING`)
- 방문차량(`VISIT`)
- 결제(`PAYMENT`)
- 기타(`ETC`)

제목은 1~200자로 입력하고 문의 내용을 작성한다. 문제 확인에 도움이 되도록 발생 시각, 이용 메뉴, 차량번호와 화면의 오류 문구를 함께 작성할 수 있다. 비밀번호, 인증번호, API 키, JWT 토큰과 금융정보는 입력하지 않는다.

## 내 문의

`내 문의`에서는 로그인한 입주민 본인이 등록한 문의만 조회할 수 있다. 문의 상세 화면에서 작성 내용, 처리 상태와 관리자 답변을 확인한다.

- 답변 대기(`WAITING`): 관리자가 아직 답변하지 않은 상태
- 답변 완료(`ANSWERED`): 관리자 답변이 등록된 상태

구체적인 답변 완료 시간은 보장하지 않는다.

## 재문의

- 관리자 답변이 완료된 문의에만 재문의할 수 있다.
- 같은 문의 흐름에 답변 대기 중인 재문의가 이미 있으면 추가 재문의를 등록할 수 없다.
- 재문의는 기존 문의의 분류와 제목을 이어받는다.

## 관리자 처리

관리자는 답변 대기 또는 답변 완료 상태별로 문의를 조회하고 답변을 등록한다. 이미 답변이 등록된 같은 문의에는 중복 답변할 수 없다.

답변 완료 후 3개월이 지난 문의는 스케줄러에 의해 지난기록으로 이동할 수 있다.

## 바로 문의해야 하는 상황

- 본인 차량, 입출차 기록 또는 주차 위치가 실제와 다른 경우
- 월 방문차량 한도 초과 후 추가 등록이 필요한 경우
- 차량번호 인식 오류 또는 게이트 통과 문제가 있는 경우
- 계정 승인, 탈퇴 또는 복원 상태를 개별적으로 확인해야 하는 경우
- 운영 규정의 예외 적용이나 관리자 판단이 필요한 경우
- FAQ와 프로젝트 안내 자료에 근거가 없는 경우
