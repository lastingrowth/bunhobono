# 차량 등록 안내

## 차량 종류

- 일반차량(`normal`): 입주민의 상시 등록 차량
- 방문차량(`visit`): 방문 예정 시간과 종료 시간이 있는 임시 등록 차량

## 현재 승인 정책

현재 차량 등록은 별도의 승인 대기 과정을 거치지 않고 즉시 `APPROVED` 상태로 저장된다.

- 관리자가 등록한 일반차량과 방문차량은 즉시 등록된다.
- 입주민이 등록한 방문차량도 즉시 등록된다.
- 차량 목록에 승인상태와 승인일 항목이 남아 있지만, 현재 등록 흐름에서는 `PENDING` 승인을 기다리지 않는다.
- 회원가입 승인 대기와 차량 등록은 서로 다른 절차다.

## 입주민의 일반차량

입주민은 일반차량을 직접 등록하지 않는다. 일반차량 등록이나 변경이 필요하면 관리자에게 요청하거나 1:1 문의를 이용한다.

관리자 등록 기준으로 일반차량은 회원 한 명당 활성 차량을 최대 2대까지 등록할 수 있다. 동일한 차량번호가 이미 유효한 차량으로 등록되어 있으면 중복 등록할 수 없다.

## 입주민의 방문차량 등록

1. 로그인 후 차량관리로 이동한다.
2. 방문차량 등록 화면에서 차량번호를 입력한다.
3. 방문 날짜와 시작 시각을 선택한다.
4. 1시간부터 24시간까지 방문 이용시간을 1시간 단위로 선택한다.
5. 입력 내용을 확인하고 등록한다.

방문 시작 시각은 현재 시각으로부터 최소 1시간 이후여야 한다. 종료 시각은 선택한 이용시간을 기준으로 자동 계산된다.

## 월간 방문차량 이용시간

세대별로 매월 방문차량 이용시간 150시간이 기본 제공된다. 방문차량을 신청하면 선택한 이용시간만큼 사용량에 포함되며, 입차 중인 방문차량을 연장한 시간도 사용량에 포함된다.

입주민 메인 화면과 차량관리 화면에서 이번 달 남은 방문차량 이용시간을 확인할 수 있다. 남은 시간이 신청 또는 연장하려는 시간보다 적으면 추가시간을 구매해야 한다.

## 방문차량 추가시간 구매

차량관리의 방문차량 추가시간 구매 화면에서 다음 상품을 카드로 결제할 수 있다.

- 2시간: 5,000원
- 10시간: 24,000원
- 30시간: 66,000원

결제가 완료된 추가시간은 해당 세대의 해당 월 방문차량 이용한도에 합산된다. 결제 실패, 결제 완료 후 시간 미반영 또는 개인별 구매내역 확인이 필요한 경우 1:1 문의를 이용한다.

## 방문차량 변경·연장·취소

- 아직 입차하지 않은 본인의 방문차량은 차량관리에서 방문 시작 시각과 이용시간을 변경할 수 있다.
- 아직 입차하지 않은 본인의 방문차량은 차량관리에서 취소할 수 있다.
- 이미 입차한 방문차량은 화면에서 취소할 수 없다.
- 현재 입차 중인 방문차량은 1시간부터 24시간까지 이용시간을 연장할 수 있다.
- 연장하려는 시간보다 남은 월 이용시간이 적으면 추가시간을 먼저 구매해야 한다.
- 이미 입차했는데 시간 변경이나 취소가 필요하거나 상태가 실제와 다르면 1:1 문의를 이용한다.

## 긴급·작업 차량

관리자는 일반 미등록 차량을 30분 방문차량으로, 긴급 또는 작업 목적 차량을 72시간 방문차량으로 즉시 등록할 수 있다. 이 기능은 관리자용이며 입주민이 직접 처리하지 않는다.

## 차량번호 입력

차량번호는 공백 없이 실제 번호판 형식에 맞게 입력한다. 이미 등록되었거나 사용 중인 동일 차량번호는 다시 등록할 수 없다. 인식된 번호와 실제 번호가 다르면 관리자 확인이 필요하다.
