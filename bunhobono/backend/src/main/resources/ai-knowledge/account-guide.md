# 계정 및 회원 안내

## 입주민 회원가입

입주민은 회원가입 화면에서 사용할 아이디, 비밀번호, 이름, 동·호수와 연락처를 입력한다.

- 아이디는 중복 확인을 완료해야 한다.
- 선택 목록에는 현재 가입 가능한 동·호수만 표시된다.
- 비밀번호는 영문, 숫자, 특수문자 `!@#$%^&*`를 모두 포함한 8~20자로 입력한다.
- 비밀번호와 비밀번호 확인 값은 같아야 한다.
- 연락처로 받은 6자리 인증번호를 확인해야 한다.
- 인증번호는 화면 안내 기준 3분 안에 입력한다.

## 가입 승인과 로그인

공개 회원가입으로 생성된 입주민 계정은 `PENDING` 상태로 저장되며 관리자 승인 후 정상 이용할 수 있다. 관리자가 직접 등록한 계정은 활성 상태로 생성할 수 있다.

로그인 상태에 따라 이용이 제한될 수 있다.

- `PENDING`: 가입 승인 대기
- `ACTIVE`: 정상 이용 가능
- `WITHDRAW_PENDING`: 탈퇴 처리 대기
- `INACTIVE`: 비활성 상태
- `ON_LEAVE`: 휴직 상태인 관리 계정

차량 등록의 즉시 승인 정책과 회원가입 승인은 서로 다른 절차다.

## 아이디 및 비밀번호 찾기

- 로그인 화면에서 아이디 찾기와 비밀번호 찾기를 이용할 수 있다.
- 계정에 등록된 연락처 또는 화면에서 제공하는 인증 수단으로 보안코드를 확인한다.
- 인증이 완료되면 아이디를 확인하거나 새 비밀번호를 설정한다.
- 인증 정보가 일치하지 않거나 코드를 받지 못하면 입력한 회원정보를 다시 확인하고, 해결되지 않으면 1:1 문의를 이용한다.

## 마이페이지

입주민은 마이페이지에서 본인 정보를 조회하고 연락처 등의 정보를 수정할 수 있다.

비밀번호 변경 시에는 다음 항목이 필요하다.

- 현재 비밀번호
- 영문·숫자·특수문자를 포함한 8~20자의 새 비밀번호
- 새 비밀번호 확인
- 화면에 표시된 보안문자

비밀번호 변경이 완료되면 다시 로그인해야 한다.

## 회원 탈퇴

회원 탈퇴는 본인 확인 절차를 거쳐 요청한다. 탈퇴 요청 상태에서는 일부 서비스 이용이 제한될 수 있으며, 관리자가 최종 처리하는 절차가 존재한다. 탈퇴 취소나 복원 가능 여부처럼 개별 계정 확인이 필요한 내용은 1:1 문의로 확인한다.

## 보안 및 개인정보

- 비밀번호, 인증번호, JWT 토큰을 상담 내용에 입력하지 않는다.
- 다른 사람의 계정, 연락처 또는 동·호수 정보는 제공하지 않는다.
- 본인 계정의 구체적인 상태는 로그인 후 마이페이지 또는 관리자 확인을 통해 안내한다.
